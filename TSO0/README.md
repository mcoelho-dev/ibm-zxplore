# TSO1 - Request 3270 Access to TSO/ISPF
IBM Z Xplore | Advanced

## Overview
Setup challenge to gain hands-on access to the traditional mainframe
interface. Involves requesting TSO/ISPF access and configuring a 3270
terminal emulator to connect to the IBM Z system.

## What I practiced
- **3270 terminal emulation** — installed and configured wc3270 to connect
  to the IBM Z mainframe environment
- **TSO/ISPF concepts** — introduction to the traditional panel-based
  interface used to interact with z/OS systems

## Tools
- wc3270 (x3270 for Windows)

## Completion
Requested and received TSO/ISPF access on IBM Z Xplore platform.
