## CODE1 — Python on IBM Z

Completed the CODE1 challenge on IBM Z Xplore.

### Topics covered
- Running Python programs on z/OS USS
- Variables and data types
- if/else conditional statements
- while loops
- Debugging logic errors
- String slicing and manipulation

### Files
- `code1.py` — introduction to Python on Z: time, userid, loops
- `code2.py` — variables and if/else: checking if a letter exists in a word
- `marbles.py` — while loop with conditional logic and visual output
