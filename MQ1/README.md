# MQ1 - Introduction to IBM MQ
IBM Z Xplore | MQ

## Overview
Introductory challenge covering what IBM MQ is, why enterprises use it,
and how it compares to other communication approaches like REST APIs.

## What I learned
- **What IBM MQ is** — a message queuing middleware that enables
  applications to communicate asynchronously by exchanging messages
  through queues
- **Why use MQ** — decouples applications so they don't need to be
  available at the same time, improving reliability and resilience
- **How it works** — a producer puts a message on a queue; a consumer
  reads it when ready, regardless of when it was sent
- **MQ vs REST** — REST requires both sides to be available simultaneously;
  MQ allows communication even when the receiving application is offline
- **Benefits** — guaranteed message delivery, scalability, and loose
  coupling between systems
