# TSO1 - Prepare for 3270 Access
IBM Z Xplore | Extended

## Overview
Setup challenge to gain hands-on access to the traditional mainframe
interface via a 3270 terminal emulator. Covers installing and configuring
a TN3270 emulator on Windows and connecting to the IBM Z system to reach
the TSO/ISPF login screen.

## What I practiced
- **3270 terminal emulation** — installed and configured wc3270 to connect
  to the IBM Z mainframe environment
- **TSO logon** — authenticated to the z/OS system using TSO credentials
  via the traditional terminal interface
- **ISPF Primary Option Menu** — successfully reached and navigated the
  panel-based environment used to interact with z/OS

## Tools
- wc3270 v4.5ga5 (x3270 for Windows)

## Connection details
- Host: 204.90.115.200
- Port: 623

## Completion
Successfully logged into TSO and reached the ISPF Primary Option Menu
on IBM Z Xplore platform.
