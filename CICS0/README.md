# CICS0 - A Basic Overview of CICS
IBM Z Xplore | CICS

## Overview
Introductory challenge covering what CICS (Customer Information Control
System) is, how it works, and why enterprises depend on it. Content
delivered through IBM Redbooks video lectures by the CICS development team.

## What I learned
- **What CICS is** — a mixed-language application server running on IBM Z,
  used by the majority of Fortune 500 companies
- **RAS qualities** — Reliability, Availability and Scalability as core
  principles of CICS design
- **Application server concept** — how CICS offloads common programming
  concerns (security, transactionality, web communication, high workloads)
  so developers can focus on business logic
- **Mixed-language support** — CICS can host applications written in COBOL,
  Java, C, PL/1 and others simultaneously, handling interoperability between them
- **Transaction throughput** — CICS has achieved over 200,000 transactions
  per second in performance studies

## Industries that use CICS
Banking, Transportation, Retail, Insurance
