## USS1 — Unix System Services

Completed the USS1 challenge on IBM Z Xplore.

### Topics covered
- SSH connection to z/OS mainframe
- USS navigation (ls, cd, pwd, mkdir, touch)
- File redirection (> and >>)
- Caesar cipher decoding with scramble.sh
- Disk usage (du -ak)
- Zowe Explorer USS view

### Files
- `ussout.txt` — final output file containing decoded message, disk usage and date
